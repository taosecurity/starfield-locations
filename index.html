Starfield Locations

This page lists every place in the official game files you can jump to with the console's coc command, with a readable name, the larger place it belongs to, and its planet and star system. Covers the base game (with the Free Lanes update), Shattered Space, Terran Armada, Watchtower and Trackers Alliance.

Basics

Using coc

Open the console with the ~ key (PC only), type coc and a place's editor ID, and press Enter: coc CityNewAtlantisLodgeInt puts you inside the Lodge. The Copy button copies the whole command.

Save first. Jumping into a quest place early can skip or break the quest. Using the console also turns off achievements for that save, unless a mod prevents it.

Cells: what coc jumps to

The game world is cut into cells. An indoor place (a shop, a cave, a ship) is one cell. Outdoor areas are grids of cells inside a worldspace, and only some of those cells have an editor ID. coc takes a cell's editor ID, the same thing this page lists.

In towns, each named outdoor cell gets its own row (Coe Plaza, the spaceport, landing pads). Elsewhere a place's outdoor cells share one row. It shows the best cell to jump to, and the others are listed under "more cells here".

Where the names come from

  • Most names are the game's own: the cell's name, or the name of the location it belongs to.
  • Many outdoor town cells have no name in the game. For those, the name is made from the editor ID: CityAkilaCityCoePlaza01 becomes "Coe Plaza". Those rows are marked name from ID.
  • "Part of" and "Planet or moon" follow the game's location chain, e.g. Infinity Limited HQ › Infinity LTD › New Atlantis, on Jemison in Alpha Centauri.

Add-ons

Places from an add-on only exist if you own and installed it. Use the buttons under the search box to show or hide each add-on. Free Lanes is a free update that every copy of the game has. The Trackers Alliance HQ comes from the free Trackers Alliance start (SFBGS003.esm); the bounty missions are the paid part.

FormIDs

The last column gives the file that adds each cell and its FormID inside that file. In your game the first digits depend on your load order. coc doesn't need the FormID, but it helps when you look a cell up in xEdit. "also:" lists the other official files that change that cell.

"More cells here"

A big outdoor place is made of many cells, and several of them can have editor IDs. Listing each one would bury the page in near-identical rows, so outside towns a place gets one row. Its coc command uses the best entry cell: the one with the map marker or the main entrance.

The other named cells of the same place are under "more cells here". Each is also a working coc target that drops you somewhere else in the same place. For example, the Freestar Mech Factory row uses LC024FrontDoor, and coc LC024FirstsHideoutLandingPad, one of its 21 more cells, puts you at its landing pad.

About this list

  • This list was read straight from the Steam game files for Starfield 1.16.244.0: the cells, locations, worldspaces and map markers in each plugin, with English names from the game's own string files. A place counts under the file that adds it. An add-on that only changes a base-game cell is noted under "also:".
  • Sorting real places from developer leftovers is done by rules (test, debug, template and holding cells, ship templates). A few may be in the wrong list.
  • The commands were not run in the game for this list. If one doesn't work, the cell may need a quest stage or may be a template.
  • Mods aren't included. A game update can add places, and the list is regenerated after updates.
  • The public copy is at https://taosecurity.github.io/starfield-locations/
