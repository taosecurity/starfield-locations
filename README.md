# Starfield Locations

Every place in Starfield and its official add-ons that you can jump to with the console's `coc` command, read from the game's own data files (game version 1.16.244.0).

**View it here:** https://taosecurity.github.io/starfield-locations/

- 1,118 places, each with a readable name, the larger place it belongs to (for example Coe Plaza in Akila City), its planet or moon, its star system, and the `coc` command with a Copy button.
- Covers the base game (with the Free Lanes update), Shattered Space, Terran Armada, Watchtower and Trackers Alliance, with buttons to show or hide each add-on.
- Grouped by star system, then planet, then the larger place; plus Popular places, a "Space only" list (planets whose only coc target is in orbit) and "No fixed planet" (procedural places).
- Search across names, places, planets, systems and editor IDs.

Made by Richard Bejtlich of [Richard Presents Starfield Essentials](https://www.youtube.com/@RichardBejtlich).

## Notes

- This is an unofficial list, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media.
- Many outdoor town areas have no name in the game; those names are built from the editor ID and marked "name from ID".
- Only editor IDs, FormIDs and English names are shown. The commands were not tested in the game for this list. Save before using `coc`: jumping into quest places early can break quests.
- The list is regenerated after game updates.

The page is a single self-contained `index.html` with no external dependencies. Its code (layout and search) is MIT licensed; see `LICENSE`.
